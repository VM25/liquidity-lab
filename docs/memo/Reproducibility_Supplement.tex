\noindent This supplement records where each result in the paper comes from: the specification that fixed it, the output that
holds it, and the version of the project repository in which each was recorded. Version identifiers are abbreviated
commit identifiers of that repository; file paths are relative to its root. Nothing here changes a result reported in the
paper.

\section{Data}

The market data are free public samples: Tardis's first-of-month captures of Binance's spot depth and trade streams for
SOLUSDT, and Binance's public trade archive, which carries complete trade identifiers and the exchange's aggressor flag.
Raw files are kept locally and are not redistributed. A data-acceptance test, run before any experiment, rebuilds the book
from snapshot anchors, marks time valid only while the book is provably correct, and writes the accepted windows of every
session to \path{results/acceptance_001/windows.csv}; its report is \path{results/data_acceptance_report.md} and its
rules are in \path{configs/acceptance_001.toml}. The splits (ten training, five validation and five test sessions) are
fixed in \path{configs/research_v1.toml}.

\section{Checks before the held-out evaluation}

Before the protocol was frozen, the evaluation code was checked on discovery sessions only. The evidence files are in
\path{results/closeout_dev/} (recorded at \path{e1c0ea7}, all produced by the evaluated code version \path{1a28aef}):
\begin{itemize}
  \item \textbf{Fitted models.} Recomputing the 24 forwarded fitted artifacts in a separate copy of the repository gave
  byte-identical files; the fitting code reproduced the frozen walk-forward models of E003 and E004 for all ten
  evaluation sessions.
  \item \textbf{Reproduction of discovery results.} Run on the discovery sessions, the evaluation code reproduced every
  frozen discovery table it re-implements: E002 (2 tables), E003 (5, including the fitted models) and E004 (7) byte for
  byte, and E001 field by field. Across the four experiments, 6{,}979 distinct frozen values matched exactly.
  \item \textbf{Coverage of compared outputs.} Every one of the 20{,}991 entries of the four frozen discovery result files
  was classified as compared or explained.
  \item \textbf{Rehearsal.} The full evaluation path ran to completion on five discovery sessions standing in for the
  test sessions.
  \item \textbf{Failure handling.} Nineteen injected failure scenarios and eighteen eligibility-check scenarios behaved as
  the protocol specifies.
\end{itemize}

\section{Software}

The replay engine and all experiments run in Python 3.12 with dependencies pinned by \path{uv.lock} and
\path{.python-version}; the session-eligibility record lists numpy 2.5.4, polars 2.0.0 and pyarrow 26.0.0. Each experiment
is a module in \path{lpx/research/} (\path{e001.py} to \path{e004.py} with their analysis modules), and the held-out
evaluation is \path{lpx/research/closeout.py} with \path{closeout_analysis.py}. The figures require matplotlib
(drawn with version 3.9.4), and the paper is typeset with pdf\LaTeX{} and BibTeX.
